# Spec: v0.4 Gold Demo Integration

## Objective
Integrate a prominent Call-to-Action (CTA) and a dedicated section for the v0.4 "Gold Demo" into the existing landing page. The goal is to provide immediate access to the live demonstration of the `ple` engine.

## Implementation Details

### 1. Hero Section CTA
- Add a new "Try the v0.4 Gold Demo" button next to or above the existing "Build the future with us" mailto link.
- **Style:** High-contrast (e.g., solid white background with black text, or a subtle orange border `#ff4500` to match the engine core node).
- **Link:** Point to the live v0.4 demo URL (TBD: Assume `https://demo.ple.simway.io` for now, or provide a placeholder for Sim to fill).

### 2. Dedicated Demo Section
- Add a new section below the "The Triangle" diagram.
- **Title:** "See it in action: v0.4 Gold Demo"
- **Content:**
    - A brief description: "Experience the transition from Chaos to Order. Watch how fuzzy human intent is transformed into a deterministic domain model and executable artifact in real-time."
    - A large, clickable screenshot placeholder (or a simple CSS card) that links to the demo.
- **Visuals:** Maintain the minimal, dark-mode aesthetic. Use thin borders (`#333`) and consistent typography.

### 3. Updated Status
- Update the `.status` text from "Private Alpha. Launching April 30, 2026." to "v0.4 Public Demo is Live."

## Acceptance Criteria
- Both CTAs link correctly to the demo URL.
- The layout is responsive and maintains the visual balance of the original design.
- The "v0.4" branding is clear and consistent.
